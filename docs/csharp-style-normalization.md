# C# style normalization

## Rules

- Normalize the standard file header and English brief.
- Match namespaces to assembly names.
- Add English XML documentation for custom types, methods, and ambiguous members.
- Apply `.editorconfig` formatting with `.claude/scripts/format-csharp.ps1`.
- Preserve runtime behavior.
